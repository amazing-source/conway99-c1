## 1. Proved reformulations (elementary)
R1 (T_S >= 0).  nu = 1 + c(l) + dim P, where P = rho_Y(ker T_S) is the space of profiles of kernel vectors on Y.
Proof: ker rho_Y = ker T_S n R^X = ker T_X by positivity, of dimension 1 + c(l).  So (N9-NG) on the side of l is
equivalent to dim P <= 8, whatever c(m) is.  This holds for grid blocks too.  The grid c22 objects have dim P = 11.
R2 (a general split, no symmetry assumed).  Let delta: P -> R^10, delta(pi)(y) = pi(2y) - pi(3y), y outer.  The
vector k_2 lies in ker T_S and has delta = 2.1.  Define:
  (ODDCONST, m side): delta(P) = R.1, i.e. x(2y) - x(3y) is the same for all ten outer y, for every x in ker T_S;
  P_0 = {pi in P : delta(pi) = 0}.
Then nu = 1 + c(l) + dim delta(P) + dim P_0.  Hence ODDCONST(m) together with (EVEN': dim P_0 <= 7) implies
(N9-NG) on the side of l.  P_0 always contains the c(m) part indicators of H_m in the non-grid case.
In the h-invariant case, ODDCONST(m) follows from ODD9-NG, and P_0 is the profile space of the h-even kernel, so
EVEN' is EVEN3-NG.  The split is therefore the symmetry-free form of ODD9-NG + EVEN3-NG (THREE_RESULTS section 8).
It is a sufficient split: (N9-NG) itself only says dim delta(P) + dim P_0 <= 8.
R3 (the h-odd sector is a signed graph).  Let Gamma_S be h-invariant.  On the h-odd sector:
  T_S = 3I - Gamma^odd - (1/8)(k_1 k_1^T + k_2 k_2^T),   with Gamma_S k_1 = Gamma_S k_2 = 0.
Proof of the identity:
  - The letter sums of an h-odd x are (lambda, -lambda, mu, -mu, 0, ..., 0), with lambda = k_1.x/2 and mu = k_2.x/2.
  - Q = (3/8)I + (1/8)Mt - (1/16)J acts as 1/4 on that vector, so x^T K x = ((k_1.x)^2 + (k_2.x)^2)/8.
  - Gamma_S k_1 = 0 by (C1): |N(s) n L_0| = |N(s) n L_1| for every s, since L_0 and L_1 lie in S.  Same for k_2.
Consequences:
  (a) T_S >= 0 on the odd sector iff lambda_max(Gamma^odd) <= 3;
  (b) odd nullity = 2 + mult_3(Gamma^odd), because eigenvectors for 3 are orthogonal to k_1 and k_2 (eigenvalue 0);
  (c) ODD9-NG iff Gamma^odd has no eigenvalue 3, i.e. iff the odd positivity is strict.
Gamma^odd is the signed quotient graph on the 22 h-orbits: the entry of a pair of orbits is Gamma(s,t) - Gamma(s,ht).
On the l-side it is a signed 2-regular graph (sigma-edges +, tau-edges -, tau-fixed points give -1 loops).
The U side behaves the same way.  For x h-odd and orthogonal to k_1 and k_2, all 14 letter sums vanish, so Pi x = x
and x^T U_S x = 4|x|^2 + x^T Gamma_S x.  Also U_S k_i = 0.  Hence:
  - U_S >= 0 on the odd sector iff lambda_min(Gamma^odd) >= -4 on the orthogonal complement of k_1, k_2;
  - the odd nullity of U_S is 2 + mult_{-4}(Gamma^odd).
So T, U >= 0 on the odd sector says exactly: spec(Gamma^odd) is contained in [-4, 3] on the complement of k_1, k_2.
ODD9-NG says that 3 is never attained there for a non-grid block.  This is the odd-sector refinement of P10
(NOTE_PROOFS_1410: nullity T_S = mult_3(A_Sigma), U_S >= 0 iff lambda_min(A_Sigma) >= -4).
R4 (C4DO for grids).  In a grid, each of the four labels of C has its four star-neighbours inside C.  So
Gamma_S w_C = -2 w_C, and since K w_C = 0 (B w_C = 0), T_S w_C = 5 w_C: w_C lies in range T_S and is orthogonal to the
kernel.  Same mechanism as the grid lemma E11 (MECHANISM_A_2026-10-15.md).

## 2. Data (exact ranks or 1e-7 tolerance; logs in hmatch_tools_2026-10-15/n9ng_attack/)
D1 (cs_ratio_test.log).  (tr R)^2 / tr(R^2) >= 2.284 on all 103 non-grid h-invariant T, U PSD structures, on both
sides (R = even residual, even_residual.py).  This certifies rank R >= 3 on those structures.  The ratio is <= 2 in
585 of 614 grids.  It is not a proof: R involves the pseudo-inverse of the whole l-side block.
D2 (do_breakdown.log).  (C4DO) x(02) - x(03) - x(12) + x(13) = 0 for every kernel vector of every structure on file

non-grid structures with mixed relations.  No local preimage was found: the minimal-norm z with T_S z = w_C is dense,
with denominator 487 on a30_id_c11_PSD_1 (c4do_minnorm.py).
D3 (oddconst_test.log, asym_law_test.log).  ODDCONST holds on both sides for all 109 non-grid T >= 0 structures.  It
fails in 756 of 2 063 T >= 0 grids and in 6 non-PSD non-grid structures (h4g_3_bestpsd, s4L_3_bestpsd, kng_1, lstest).
Only 2 of the 109 have none of the tested symmetries (h, (0 1)M, (2 3)M, (0 1), (2 3), hM, M); both are in the
asym_schur_c11_PSD_3912 lineage.  Independent support beyond the h-invariant case (where it is ODD9-NG) is therefore

D4 (oddconst_test.log).  EVEN': dim P_0 <= 7 on all 109 non-grid T >= 0 structures.  The value 7 is attained at
nu = 14 (40 of 40), 13, 12, 11 and 10.
D5 (odd_spectral.log).  R3 checked: odd nullity = 2 + mult_3(Gamma^odd) on all 743 h-invariant T >= 0 structures.  In
the 107 non-grid ones mult_3 = 0, but 3 minus the largest eigenvalue below 3 goes down to 0.0071.  There is no uniform
gap, so a proof of ODD9-NG must be exact (algebraic), not quantitative.
D6 (line_gains.py, subset_gains.py, rel_table.py; regularity of the tight cases).
  - Definitions: f(A) = rank gain over V_X of the m-blocks C_mn = {2y, 2y', 3y, 3y'} for n in A (a set of outer
    lines); rel(A) = 4|A| - f(A) = dimension of the kernel profiles supported on those blocks.
  - Tight non-grid structures tested (ng14_1 with c55, a30_id_c11 with c11, ng_c11, the l-side of asym31): rel = 3 for
    every 3 lines, 5 for every 4 and 8 for all 5, whatever c and the parts are.
  - Each single block carries a 3-dimensional profile space whose annihilator is exactly the doubly-odd functional
    pi(2y) - pi(2y') - pi(3y) + pi(3y') (DO), whatever the local adjacency.
  - Two blocks carry 5 dimensions; the extra annihilator says that delta is the same on both lines (cross-line
    ODDCONST).
  - Grid c22 (asy_c22_H30_1): rel = 2|A| for |A| <= 4 and 11 for all 5; each block alone gains only 2 over V_X.
  - In G1-invariant tight structures (sector_nullity.py) the 2 mixed relations sit in the (h-even, (0 1)M-odd) sector
    (dimension 11).  The (h+, f+) sector carries exactly the c(l) + c(m) side relations, and the two odd sectors carry
