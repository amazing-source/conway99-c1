# Lemmes de réduction pour c ≤ 2, et bilan du run zscan1 — 18/10/2026 au soir (LAB)

Demande de l'utilisateur : « continuer à tenter de réduire à la main les cas c = 3, c = 2 et c = 1 avec des lemmes, en
regardant ce qui meurt, pourquoi ça meurt et comment tout faire mourir ou au moins une grande partie ».

Statuts employés : **démontré** (preuve écrite ici à partir de faits sourcés), **mesuré** (calcul exploratoire, verdicts
CP-SAT sans certificat), **donnée** (sortie d'un run).

## 1. Faits utilisés (aucun n'est nouveau)

Racine x, 7 droites, 84 étiquettes, 21 rectangles de 4 coins. Pour une étiquette w et un rectangle F :
z_w(F) = |N(w) ∩ F|, et h_w(F) = base(w, F) − z_w(F), avec base = 2 (rectangle de w), 0 (une droite commune), 1 (disjoint).

- (F1) Équations de composante : pour toute racine r et tout bloc P de r, Σ_{j∈P} h_w(Q_rj) = 0.
  Source : Tσ = 0 sur chaque composante (AUDIT_EXCLUSIONS_2026-10-18.md, §3 item 5), et H = TP.
- (F2) Si F est une grille, alors h_w(F) = 0 pour tout w. Source : R_FF = 8 − 2e(F) = 0 et HᵀH = 7R (item 3).
- (F3) Bornes : 0 ≤ z_w(F) ≤ 2 si F rencontre le rectangle de w, et 0 ≤ z_w(F) ≤ 4 sinon.
  Preuve directe. Soit w ∈ Q_ab, adjacente à la lettre a* de la droite a. Les étiquettes voisines de w adjacentes à une
  lettre de a sont exactement deux : la voisine commune de w et a* (λ = 1), et la voisine commune de w et a′ autre que a*
  (μ = 2). Donc Σ_{F∋a} z_w(F) = 2.
- (F4) Si les quatre coins de q ont un compte propre 2, alors q est une grille.
  Preuve. À la racine a, chaque coin a ses deux voisines-étiquettes de G_{l_a} dans q (F3). L'unité {b*, b′} ∪ coins(q) est
  donc fermée dans G_{l_a}, c'est une composante, et {b} est un bloc singleton de a.

## 2. Les lignes sont des pondérations à somme nulle du graphe des blocs

**Graphe des blocs Ĵ d'un gabarit.**
- Sommets : un sommet (r, P) par racine r et bloc P de taille ≥ 2.
- Arêtes : une par rectangle non grille {r, s}, qui joint (r, bloc de s en r) à (s, bloc de r en s). Il n'y a pas de boucle.

Par (F1) et (F2), la ligne h_w d'une étiquette w est un vecteur entier sur les arêtes de Ĵ, de somme nulle en chaque
sommet de Ĵ. Elle est dans la boîte de son rectangle q = {a, b} :
- h(q) ∈ [0, 2] ;
- h(e) ∈ [−2, 0] pour une arête e ≠ q qui rencontre q ;
- h(e) ∈ [−3, 1] pour une arête disjointe de q.

C'est une réécriture des équations de Codex (`row_catalogue`), pas un fait nouveau.
La dimension de l'espace (kernel_dimension du recensement) vaut m − n + (nombre de composantes biparties de Ĵ).

## 3. Lemme FG (« grille forcée ») — démontré

**Énoncé.** Soit q = {a, b} un rectangle non grille. On cherche une marche fermée de Ĵ qui passe par q et alterne les
signes. Les arêtes positives sont q et les arêtes disjointes de q. Les arêtes négatives sont les arêtes ≠ q. S'il n'existe
pas de telle marche, le gabarit est impossible.

**Preuve.**
1. Soit h la ligne d'un coin u de q.
2. En chaque sommet de Ĵ, h a autant d'unités positives que négatives. On fixe une bijection entre elles en chaque sommet.
3. On part d'une unité positive de q et on suit les bijections. Cela définit une permutation d'un ensemble fini d'états
   (unité, extrémité). L'orbite est donc un cycle : c'est une marche fermée alternée qui passe par q.
4. Les signes y sont ceux de h, donc ceux qu'autorise la boîte.
5. Sans telle marche, h(q) = 0 pour chaque coin, donc chaque coin a un compte propre 2.
6. Alors e(q) = 4 et q est une grille (F4). Contradiction.

E3 n'est pas utilisé.

**Test.** Recherche en largeur sur les états (sommet de Ĵ, signe de l'arête d'arrivée), depuis l'extrémité b après q
traversée positivement. La cible est l'extrémité a atteinte par une arête négative.
- La recherche est exhaustive, donc le verdict « aucune marche » est exact. Coût : environ 0,5 ms par gabarit.
- Code : `jhat_rows.py`, fonction `forced_grid_walk`.
- Contrôle (`--ilp`) : un modèle entier exact, sans relâcher les multiplicités. Sur les 419 gabarits de l'échantillon,
  tout rectangle forcé selon la marche est forcé selon le modèle entier. Le modèle entier en force quelques-uns de plus
  (au plus 2 gabarits par famille).

Exemple fait à la main (gabarit 314 de l'échantillon, e2s_k06, q = Q45) :
1. En 6, le bloc {0, 4, 5} donne h(06) + h(46) + h(56) = 0.
2. h(46) = 0 car 6 n'est pas dans le bloc de 5 en 4 ; h(56) = 0 car 6 n'est pas dans le bloc de 4 en 5. Donc h(06) = 0.
3. En 0, le bloc {5, 6} donne h(05) = 0.
4. En 5, le bloc {0, 4} donne h(45) = −h(05) = 0.
5. Donc le compte propre vaut 2 pour chaque coin, et Q45 serait une grille.

## 4. Lemmes M1 et M2 (un seul rectangle, moments) — identités démontrées, projections mesurées

Pour une cible non grille q avec e = e(q) ∈ {0, 1, 2} (E3), on utilise :
- les histogrammes des coins ;
- Σ h_w(q) = −(16 − 4e) sur les étiquettes à une droite commune avec q ;
- Σ h_w(q) = 8 − 2e sur les étiquettes disjointes ;
- Σ_w h_w(q)² = 7(8 − 2e), colonne q de HᵀH = 7R.

Ce sont les identités du `check_rectangle` de Codex, réécrites avec h.

- **M1** : chaque étiquette d'une classe G prend h(q) dans la projection exacte V_G(q) des lignes de G. Ces projections
  sont calculées par CP-SAT, une valeur à la fois, sans limite de dimension (c'est ce qui manque à l'outil de Codex au-delà
  de la dimension 6).
- **M2** : M1, plus la symétrie Σ_{w∈G} h_w(q) = R_Gq = R_qG = Σ_{u∈q} h_u(G), avec les quatre lignes des coins explicites
  (modèle CP-SAT). Code : `jhat_moment.py`.

Statut : les identités sont démontrées. Les verdicts d'infaisabilité sont des verdicts CP-SAT (mesure) ; il n'y a pas
encore de certificat.
