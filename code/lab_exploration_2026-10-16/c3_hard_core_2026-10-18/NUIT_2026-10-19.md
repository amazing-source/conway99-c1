Notations : l une droite, G_l le graphe cubique induit sur les 36 sommets N(l), D les 60 sommets lointains, N l'incidence
N(l) × D, E_p la matrice « même point de l ».

**Identité.** Le bloc (N(l), N(l)) de A² = 12I − A + 2J donne :

    N Nᵀ = 12 I + 2 J − E_p − A_G − A_G².

Comme A_G E_p = J, sur ker E_p cette matrice vaut −(A_G − 3)(A_G + 4).

**Conséquences.**
- rang N = 35 − c(l).
- ker Nᵀ = span{g_α} ⊕ {Σ c_K χ_K : Σ c_K s_K = 0}.
- d^K = s_K, c'est-à-dire l'équidistribution, soit (F1).
- dim(E₃ ∩ R^D) = 18 et dim(E₋₄ ∩ R^D) = 7 + c(l).
- spec Γ[D] = {8, 3^18, (−4)^(7+c)} ∪ {−1 − θ : θ ∈ spec G_l privé de 3^c et 0²}.
- La preuve de Codex pour une droite tout-grille (2777ca92) est le cas c = 6.

**Contrôle positif refait** (`line_spectrum_2026-10-18/line_spectrum_control.py`, sortie `…_srg243.out`).
- La version k = 22 vaut pour les 4 srg(243,22,1,2) connus : 120 droites de BvLS et les 891 droites de chacun des trois
  autres, avec c ∈ {2, 3, 4, 5, 7, 10}. Résultats : ker Nᵀ = span{g_α}, rang N = 58, m₄' = 72, m₋₅' = 50, spectre de Γ[D]
  exactement prédit.
- Le mécanisme général est le suivant : la somme sur ker Nᵀ ⊖ g_α de (θ − r)(θ − s) est nulle. Comme θ ≤ 3 :
  - pour k > 14, ker Nᵀ ⊖ g_α est nul ;
  - pour k = 14, il est formé de vecteurs propres 3 de G_l (les composantes).

**Usage cette nuit.** Aucune exclusion n'en découle. Ses conséquences sont des conséquences des C2 sur N(l) × N(l) :
elles n'ajoutent rien à un modèle qui a toutes les C2.

## 7. Colonnes opposées forcées, cœurs et familles (18-19/10, 22 h 30 – 00 h 45 UTC)

Statuts : **démontré**, **calcul exact** (énumération finie sans solveur), **vérifié LAB** (recalcul indépendant).

**(a) Relation universelle, démontrée.** À toute racine a d'un sommet quelconque d'un Conway, Σ_{b≠a} H_ab = 0, pour tout
gabarit : c'est la conséquence des seuls quotas des deux lettres de a.
- Pour toute bipartition (X, Y) des 7 droites, on en déduit Σ_{e⊂X} H_e = Σ_{e⊂Y} H_e.
- Avec les relations de blocs et les grilles, on obtient l'espace exact W des relations de colonnes. Le calcul se fait en
  arithmétique rationnelle (`two_term_relations.py`).
- Une relation H_A = ±H_B impose, ligne par ligne, z_w(A) ± z_w(B) = base_A(w) ± base_B(w) : ce sont des comptes de voisins
  imposés pour toutes les étiquettes.
